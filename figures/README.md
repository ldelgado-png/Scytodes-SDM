# Figures

These figures are working outputs from the exploratory R visualization of the Wallace prediction raster (`fc.LQ_rm.1.5_cloglog`).

- `prediction_map.jpg`: continuous cloglog suitability map without occurrence points.
- `prediction_map_occurrences.jpg`: same map with occurrence localities from the combined dataset (new manuscript records and GBIF records).
- `suitability_histogram.jpg`: frequency distribution of continuous cloglog values.

Before manuscript submission, replace these working images with publication-ready exports that include country boundaries, scale bar, north arrow, legend, projection and source metadata. The prediction raster itself is not yet stored in this repository.
