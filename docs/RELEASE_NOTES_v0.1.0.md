# Release candidate 0.1.0

Date: 2026-10-04

This release candidate contains the reproducible exploratory climatic suitability analysis associated with the manuscript on Scytodes in Colombia and Venezuela.

Included:
- occurrence data with provenance, including the formal GBIF download DOI;
- Wallace session object and selected cloglog raster;
- candidate-model evaluations and fold-level results;
- response curves, evaluation plots, masked environmental layers and background extent;
- working figures and citation metadata.

Interpretive status:
The selected LQ, RM=1.5 model is retained for exploratory mapping among nonconstant candidates. Its mean validation AUC is 0.582 ± 0.152, while constant models have lower AICc. The output must therefore be interpreted as a hypothesis-generating survey surface, not as a validated range boundary or occurrence probability.

Before formal publication, the authors must complete voucher and coordinate review, confirm redistribution permissions, create a public GitHub release, and archive this release with a DOI. The GBIF download DOI is separate from the archive DOI for the complete workflow.
